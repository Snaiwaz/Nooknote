# 浮笺（Floatnote）

桌面侧边速记工具的交互原型。当前是可在浏览器中打开的单页原型，产品规则记录如下。

## 第一版（v1.0.0）

### 产品目标

让灵感和备忘可以在不切换应用的情况下快速收录。触发入口平时尽量不打扰视线，需要时从屏幕边缘唤出。

### 交互规则

- 同时只有一个边缘触发条；初始位于屏幕右侧中部。
- 触发条平时是一小段低对比度细线，鼠标靠近时微微显现。
- 鼠标在触发条停留约 150 毫秒后打开速记面板；离开触发条和面板组成的区域后收起面板。
- 未提交的草稿保存在本机。收起或重新唤出不清除草稿，重新唤出后光标回到草稿末尾。
- 按 Enter 将草稿保存到快速收件箱；Shift+Enter 换行。中文输入法确认候选词时，Enter 不提交记录。
- 保存后清空编辑区，面板保持打开，方便连续速记。
- 收件箱按时间倒序排列，显示正文预览和时间；点击一条记录展开全文，删除入口位于详情中。
- 拖动触发条时，细线自然收拢成水滴。水滴跟随鼠标方向旋转，移动越快拉伸越明显，转向时产生轻微回弹；松开后吸附到最近的屏幕边缘并恢复为细线。
- 触发位置、草稿和收件箱记录都保存在本机，不做账号或云同步。
- 在桌面应用形态下，窗口关闭按钮只隐藏应用；从系统托盘选择“退出”才完全关闭。开机启动可选，默认关闭。

### 首版范围外

- 本仓库当前只包含浏览器原型，尚未实现系统托盘、全局边缘检测、桌面窗口常驻或开机启动。
- 首版不包含快捷键唤出、分类、搜索、云同步和账号体系。

## 运行

直接在浏览器中打开 `index.html`。草稿、记录和触发位置保存在当前浏览器的 `localStorage` 中。
